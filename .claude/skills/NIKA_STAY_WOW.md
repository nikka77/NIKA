## Scoring WOW pour NIKA
Avant d'intégrer un logement dans NIKA STAY WOW, appliquer ce score :
```typescript
interface WowScore {
  rarity: 1-5;        // Existe-t-il des équivalents ? 5 = unique au monde
  viral: 1-5;         // Potentiel TikTok/Instagram
  experience: 1-5;    // L'hébergement EST l'expérience, pas juste un logement
  accessibility: 1-5; // Facilité de réservation/accès
  commission: 1-5;    // Potentiel de commission (direct ou affiliation)
}
// Score minimum pour intégrer dans NIKA STAY WOW : 18/25
// Score 20+ : contacter propriétaire pour réservation directe
// Score 25 : priorité absolue + contenu éditorial dédié
```

## Stratégies de recherche par plateforme

### Sur Booking.com
```
Mots-clés qui fonctionnent :
"unusual accommodation" / "unique stays" / "eco lodge"
"lighthouse" / "treehouse" / "cave hotel" / "yurt"
"converted" / "historic" / "architectural"
Mots-clés qui NE trouvent PAS d'équivalents WOW :
"submarine" / "missile silo" / "cob house" / "earth house"
"airplane converted" / "crane hotel"
```

### Sur Homestay.com
```
Chercher : logements chez l'habitant INSOLITES
Points forts : commission 30%, sélection manuelle, lieux uniques
Chercher : "unique home" + pays cible
Éviter : logements chambres standard
```

### Sur Travelpayouts / Viator
```
WOW STAY → Booking.com via Travelpayouts
ACTIVITÉS connexes → Viator (visites silos, tours bunkers, etc.)
NB : Viator a des VISITES de bunkers/silos même si pas de nuitées
→ Croiser nuitée propriétaire direct + activité Viator = offre complète
```
